================================================================================
RADIATION DAMAGE ML PIPELINE - MVP OUTPUTS REFERENCE
================================================================================
Project: radiation_damage_ml
Stage scope: MVP (stage 1 and stage 2 only)

This file describes every file produced by the MVP pipeline, what each
quantity means, and how to load it. Stages 3 to 6 (energy evaluation, graph
transform, storage, dataloader) were removed from the MVP tree. Their outputs
described here in earlier revisions are no longer produced.

All outputs are written under:
    data/      binary and structured data (generated, not tracked)
    outputs/   human readable summaries and this file

All paths are anchored to the project root, so the pipeline can be launched
from any working directory.

================================================================================
STAGE 1 - DATA MINING (data/raw_structures/)
================================================================================

Source: a local CIF file, by default materials/Al.cif.

Files produced:
--------------------------------------------------------------------------------
  <material_name>.cif
      Normalised copy of the input crystal structure, readable by ASE, VESTA,
      or CrystalMaker. Contains the unit cell vectors and atomic positions.

  <material_name>.json
      Bulk metadata dictionary. Fields:
          material_name        material identifier, e.g. "aluminum"
          num_atoms            number of atoms in the unit cell
          chemical_formula     reduced chemical formula, e.g. "Al"
          lattice_parameters   dict with a, b, c (Angstrom) and
                               alpha, beta, gamma (degrees)
          source               always "local_file" for the MVP
          file_path            path to the input CIF that was read

================================================================================
STAGE 2 - DEFECT ENGINEERING (data/defect_structures/)
================================================================================

The unit cell from stage 1 is expanded to a supercell (default 2x2x2) and a
single atom is removed to create one vacancy. The default vacancy index is 0.

Files produced:
--------------------------------------------------------------------------------
  <material_name>_vacancy.extxyz
      Extended XYZ file of the defective supercell. Contains the cell vectors
      and Cartesian coordinates (Angstrom). The per structure info block also
      carries material_name, defect_type, vacancy_index, and supercell_size.
      Load with:
          from ase.io import read
          atoms = read("data/defect_structures/aluminum_vacancy.extxyz",
                       format="extxyz")

  <material_name>_vacancy.json
      Defect metadata dictionary. Fields:
          material_name      material identifier
          defect_type        always "single_vacancy" in the MVP
          vacancy_index      index of the atom that was removed
          supercell_size     supercell multiplier, e.g. [2, 2, 2]
          num_atoms_bulk     atom count in the original unit cell
          num_atoms_defect   atom count in the defective supercell
          bulk_formula       chemical formula of the pristine structure
